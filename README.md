# rythm

次世代の音ゲーの「ノーツの取り方」を試すためのプロトタイプ置き場です。
どのプロトタイプも HTML ファイル 1 枚で動き、ビルドは不要です。

## プロトタイプ

### 編み込みレーン（Kumihimo Lanes）

`prototypes/braided-lanes/index.html` をブラウザで開くと遊べます。

- 4 本のレーンが組紐のように交差し、入れ替わり、ねじれます。
- キーは画面上の位置ではなく、レーンの色につながっています（D＝紅、F＝山吹、J＝浅葱、K＝藤）。
- 譜面は固定です。BPM 128、44 小節、約 1 分 25 秒。
- 曲は Web Audio API でリアルタイムに合成しているので、音源ファイルはありません。
- タイトル画面で、ハイスピード・判定オフセット・オートプレイを設定できます。
- スマホでは判定ラインの受け皿をタップして遊べます。

譜面（`BARS`）と編み込みの動き（`BRAIDS`）は、ファイル内のデータを書き換えるだけで調整できます。

### 変形する多角形（Kiriko Gate）

`prototypes/polygon-gate/index.html` をブラウザで開くと遊べます。

- 画面中央の多角形の辺が、それぞれ 1 本のレーンです。ノーツは外側から辺に向かって迫ってきます。
- 多角形は回り続け、曲の展開に合わせて 三角 → 四角 → 五角 → 六角 と形が変わります。辺は伸びて生まれ、縮んで消えます。
- 6 本の辺にはそれぞれ固定のキーと色があります（S D F J K L）。形によって使うキーが変わります。
- ノーツは「着弾するときの形」の辺として飛んでくるので、形が変わる前から次の形が見えます。
- スマホでは、中心から見て辺がある方向をタップします。
- BPM 140、44 小節、約 1 分 15 秒。曲は Web Audio API で合成しています。

譜面（`BARS`）、形の変化（`MORPHS`）、追加の回転（`TURNS`）はファイル内のデータです。
