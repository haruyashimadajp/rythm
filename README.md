# MINAMO（水面のリズム）

雫が落ちて広がる波紋が、水面に浮かぶノーツに**届いた瞬間**に叩く音楽ゲームです。
`index.html` と、録音された曲の音源（`audio/`）で動きます。
録音の曲は音源を読み込むので、ファイルを直接開くのではなく、ウェブサーバー経由で開いてください（例：`python3 -m http.server` を実行して `http://localhost:8000/` を開く）。

このブランチ（`minamo`）は、Rhythm Lab の「広がる円（MINAMO）」形式だけに絞ったゲームです。
ほかの形式の試作は元のブランチに残っています。

## 遊び方

スマホ専用です（縦持ち）。ノーツを指で直接タップします。パソコンで開いた場合、クリックは指1本のタップとして扱われます。
- **ノーツの種類**
  - タップ：波紋が届いた瞬間に叩きます。
  - 長押し：波紋と一緒に外へ動く光を、押したまま追いかけます。
  - 回る長押し：渦を巻くように回りながら外へ動く光を追いかけます。
  - 水切り：跳ねてくる石が着水する点を叩きます。石は一定の速さで飛ぶので、着水点の間隔がそのままリズムです（間隔が倍なら時間も倍、細かい刻みは近くに並びます）。
  - 交点：二つの波紋が交わる **2点** に同時に出るノーツです。二本指で2点を同時にタップします。
  - 和音：1つの波紋が同時に届く3点・4点です。点線で結ばれ、同じ番号が付きます。指の本数で同時にタップします。
  - 連打：横に並んだ2つの点に、右・左・右…と交互に波紋が届きます。両手の親指で1つずつ受け持って交互に叩きます。縁の点の数が、その点の残りの回数です。
  - 文字盤のノーツ：判定の輪が止まっていて、ノーツのほうが中心から（または外から）輪に向かって動いてきます。輪に重なった瞬間に叩きます。

ノーツの中の数字は、その小節の中で押す順番です（小節ごとに 1 から数え直します。交点の2点は同じ数字です）。次の小節の数字は少し暗く表示されます。
連打は、中の数字が順番、縁の点が残りの回数です。設定で数字を消すこともできます。
叩ける範囲はノーツの見た目より広く、ノーツの半径の約2.7倍（最低でも40ピクセル）まで届きます。

タイミングの判定は、拍の前後 0.05 秒以内が PERFECT、0.1 秒以内が GREAT、0.15 秒以内が GOOD です。長押しは終わりの 0.15 秒前から離しても大丈夫で、光から 0.25 秒までなら外れても続きます。

判定に使う波紋（まだ叩くノーツが乗っている波紋）は太く明るく、残像や叩き終わった波紋、ソナーなどの飾りの波紋は薄く描いています。

## 設定と一時停止

- **設定**（曲選択・曲のタイトル・一時停止の画面から開けます）：音楽の音量、タップ音の音量、ハイスピード、判定オフセット、背景の演出（鯉・花火・雪・オーロラなどの飾り）のオン／オフ、画面の揺れとフラッシュのオン／オフ、ノーツの順番の数字のオン／オフ。設定と自己ベストは端末に保存されます。
- **一時停止**：プレイ中に右上のボタンで止まります。別のタブに移ったときも止まります。一時停止の画面から「再開」（3・2・1 と数えてから、止めた所から続きます）、「やり直す」、「設定」、「演奏中止」を選べます。長押しの途中で止めた場合、その長押しは止めた所から自動で最後まで取られます。

## 曲

1. **SHIZUKU 雫**（Lo-fi Hip Hop、BPM 84、レベル2）
   雨の夜の水たまりです。水面一面に雨の輪が広がり、街灯が水に映って揺れます。
   軒先の雫（同じ点の連打）、二つの雨粒の交点（同時押し）、窓を伝って流れる雫（中心が動く波紋）。
2. **KOI 鯉**（Disco House、BPM 124、レベル4）
   陽の差す池です。鯉が泳ぎ、蓮の花がキックに合わせて弾みます。光の網が水底に揺れます。
   波紋を連れて泳ぐ鯉（中心が動く波紋）、鯉の口パク（連打）、二匹の鯉の交点（同時押し）。
3. **KOORI 氷**（Waltz 3/4、BPM 168、レベル5）
   凍った湖の夜です。波紋が六角形に広がり、叩くと氷にひびが走ります。雪が降り、オーロラがかかります。
   波紋を連れて滑るスケーター、凍りついて止まる波紋（減速）、岸の向こうからの巨大な氷の波。
4. **TOUROU 灯籠**（Matsuri Rock、BPM 150、レベル6）
   夏祭りの夜の川です。灯籠が流れ、サビでは花火が上がります。太鼓、鉦、三味線、篠笛、ギターが鳴ります。
   太鼓の「ドコ」（連打）、波紋を乗せて流れる灯籠、開いてから止まる花火の波紋、二つの花火の交点（同時押し）。
5. **UZU 渦**（Drum & Bass、BPM 174、レベル8）
   嵐の渦潮です。渦が回り、ドロップでは雷が落ちて画面が揺れます。
   雷が落ちた所からの衝撃波、渦の目の周りを回る波紋、渦の目へ引き込まれて縮む波紋。

6. **PRISM 分光**（Melodic Trance、BPM 128、レベル7、録音）
   白い光が赤・緑・青の波紋に分かれて違う速さで広がり、色が交わる点で白い光になります（交点）。
   光源が縁を滑って糸の模様を描き、巨大な光の波が隅から押し寄せ、鏡の区間では波紋が左右に映ります。
7. **ABYSS 深淵**（Deep Sea Ambient、BPM 90、レベル7、録音）
   雫が沈みながら広がり、チョウチンアンコウの光から波紋が流れ、クラゲは広がっては縮む波紋で脈打ちます。
   暗い海ではソナーが届くまでノーツが見えず、反響が同じ点を連打させます。最後は深淵が波紋を引き込み、クジラの歌に乗って漂います。
8. **MALWARE 感染**（Glitch / Dubstep、BPM 150、レベル8、録音）
   四角いピクセルの波紋です。感染は叩いたノーツから次の波紋へ広がり、波紋は瞬間移動し、巻き戻り、
   テープが止まるとブルースクリーンへ落ち、フォーマットされて電源が切れます。

9. **TOKEI 狂い時計**（Hardcore、BPM 63〜320、レベル10、録音）
   狂った時計塔が水の底に沈んでいます。テンポが何度も変わり（ソフラン）、波紋は曲と一緒に速くなり、遅くなり、時間停止で止まります。
   オルゴールの巻き上げ（126）→ 1拍ごとに加速して暴走（210）→ 時間停止 → 文字盤（168、252）→ 静かな水（84、巻き戻し）→ 再起動（240）→ 軋み（120、停止）→ 暴走II（252、16分音符の駆け上がり）→ 1拍ごとに加速 → オーバークロック（320）→ 真夜中の12の鐘（63）。
   譜面の決まりごと：
   - 速い所は、画面の外から来る巨大な波紋が判定線のように横切り、ノーツは鍵盤のように音の高さで並びます（右ほど高い音）。小節の頭の和音は横一列の3点・4点です。
   - 暴走IIでは1小節おきに、後半が16分音符の音階（下がって戻る形）になります。判定線の上に、音の高さどおり細かく並びます。
   - 静かな所のメロディは、雫から扇のように広がります（外ほど後、時計回りほど高い音）。
   - ドラムロールもフーバーのトリルも、左右2点の交互連打です。
   - 文字盤では、音の高さごとに時刻が決まっています（D が12時、E が2時、F が3時……C# が11時）。半音ずつ上がるフレーズは時計を一周します。増三和音は正三角形、減七和音は正方形の4点同時押しです。
   - 最後は12の鐘が1時から12時まで順に鳴り、ノーツの番号がそのまま時刻になります。
   音楽は `songs/tokei-compose.py` が作曲・合成した録音（`audio/tokei.mp3`）です。譜面のノーツはすべて曲の中の音で、叩く瞬間にその音が鳴ります（オルゴール、時計のチャイム、スーパーソウ、フーバー、ピアノ、塔の鐘、スネアロール）。
   その周りに、ハードコアのキック、オフビートのベース、ゲートのかかったシンセ、ブレイクビーツ、弦と聖歌隊のパッド、時計の針の音、ゼンマイを巻く音、歯車の軋み、ライザー、テープストップ（時間停止）、音が一瞬に引っかかるフリーズ（2回目の停止）、逆再生（巻き戻し）、ゴングを重ねています。
   文字盤と鐘は、スマホを縦に持ったときに12時が上に来る向きで作っています。
   演出：水の底の大きな時計と歯車、振り子が拍で動くので、テンポと一緒に速く・遅く・逆回りになり、時間停止では止まります。停止中は世界が灰色になります。激しい所ではガラスにひびが入ります。

1〜5 の音は Web Audio でその場で合成しています。6〜8 は dodge-game のオリジナル曲の音源（`audio/`）を使い、
譜面はその曲の楽譜データ（作曲プログラムが書き出した拍のデータ）に合わせて作っています。
9 は dodge-game と同じやり方で、このリポジトリの `songs/tokei-compose.py`（Python、numpy と scipy）が作曲・合成した音源です。

## ファイル構成とビルド

`index.html` は `src/` の部品をつなげて作っています。編集するのは `src/` のほうで、編集後に `./build.sh` を実行すると `index.html` が作り直されます。

- `src/00-engine.html`：画面、判定、入力、音の土台、メインループ
- `src/10-field.js`：全曲共通の水面（譜面の書き方、波紋とノーツの描画、エフェクト）
- `src/20-shizuku.js` 〜 `src/95-tokei.js`：1曲ずつ（`src/94-tokei-score.js` は作曲プログラムが書き出すデータ）
- `audio/`：録音の曲の音源
- `songs/`：曲を作るプログラム
  - `songs/dump-chart.js`：譜面のノーツ（拍・長さ・音の高さ・楽器）を JSON に書き出します
  - `songs/tokei-compose.py`：その JSON から TOKEI を作曲・合成し、`audio/tokei.mp3` と `src/94-tokei-score.js`（キックの拍）を書き出します
  - 作り直す手順：`./build.sh` → `python3 -m http.server 8765` を起動 → `node songs/dump-chart.js tokei > songs/tokei-notes.json` → `python3 songs/tokei-compose.py` → `./build.sh`
- `src/99-boot.html`：起動処理

## 曲の追加のしかた

`src/` に `70-xxx.js` のようなファイルを作り、`rippleSong({...})` を1つ書きます。番号順に曲選択に並びます。

- 曲の情報：`id`、`title`、`jp`、`genre`、`level`、`lede`、`theme`（パネルの色）、`hues`（波紋の4色）
- テンポと構成：`bpm`、`beatsPerBar`（3なら3拍子）、`bars`、`sections`、`chords`
- 波紋：`speed`（1拍で広がる距離）、`ring: { sides: 6 }` で多角形の波紋、`ring: { chroma: true }` で虹色のにじみが付きます。
- 録音の曲：`audioFile: { src: 'audio/xxx.mp3', t0: 0.5 }`（`t0` は音源の中で0拍目が来る秒数）、`pulse: kickPulse([キックの拍...])`
- 譜面 `chart({ drop, skip, B })`
  - `drop(B(小節, 拍), [x, y], 色, 'パターン', { a, turn, speed, spin })`
    雫を落とします。パターンは8分音符ごとに書き、`o` はタップ、`H` は長押し、`S` は回る長押し、`-` は長押しの続き、`.` は休みです。
  - `drop` の波紋の動き：`speed` を負にすると縮む波紋、`r0` で最初から大きい波紋（中心を画面外に置くと巨大な波紋）、
    `accel` で加速・減速、`path: [[拍, x, y], ...]` と `ease`（`'smooth'`／`'linear'`／`'step'`＝瞬間移動）で中心が動きます。
    `angs` で各ノーツの角度を直接決められ、`dark: true` でノーツが隠れます。
  - `skip(B(小節, 拍), [x0, y0], [x1, y1], 色, 'パターン')`
    石が `[x0, y0]` から `[x1, y1]` へ一定の速さで跳ねていきます。`o` の位置で着水し、着水点の間隔は時間の間隔に比例します。
  - `wave(拍, [x, y], 色, { reveal: true })`：ノーツのない波紋。`reveal` で通り過ぎた暗いノーツを見せます（ソナー）。
  - `pulse(拍, [x, y], 色, { a, off, n, gap, spread, keep })`：`n` 回の連打。横に並んだ2点（`spread` だけ離れた点、縦持ちの画面で左右）に交互に届きます。`keep` を付けると1点目を `[x, y]` の位置のままにして、2点目をその横に置きます。
  - `cross(拍, 雫A, 雫B)`：二つの波紋がその拍に交わる2点にノーツを置きます（交点、2点の同時押し）。2点とも水面の中に入るように置きます。
  - `tip(雫, i)`：雫の i 番目のノーツの拍と位置。次の雫をそこから落とすときに使います。
  - `chord(拍, 雫, [角度...])`：1つの波紋に同時に届く複数のノーツ（和音、同時押し）。
  - `tap(雫, 拍, 角度, { len, spin })`：雫の波紋に1つノーツを置きます（`len` 拍の長押しにもできます）。
  - `dial(拍, [x, y], 色, 半径, { v, dir })`：止まった判定の輪。ノーツは `tap` や `chord` で置くと、中心から（`dir: -1` なら外から）1拍に `v` ずつ輪へ向かって動いてきます。
  - `drop` などの `show`：その雫のノーツを、雫が落ちる何拍前から見せるか（画面が混み合う所で使います）。
  - テンポが変わる曲：`tempo: [[拍, BPM, 予告], ...]`、`stops: [[拍, 秒], ...]`（その拍のあと、その秒数だけ止まります）。波紋は拍で動くので、テンポに合わせて速さが変わり、停止で止まります。
  - 水面の座標は、横が約 ±0.74、縦が約 ±0.42 です。
  - 遠すぎて間に合わない並びや、重なる位置にあるノーツは、読み込み時にコンソールへ警告が出ます。
- 音 `song`
  - `lead`：ノーツの音色
  - `arrange(add, bar, b0, ch, name)`：伴奏
  - `instruments`：その曲だけの楽器
  - `extra(add, addAt)`：小節によらないフレーズ（`addAt` は秒で置くので、停止中の音にも使えます）
  - `leadVoice(note)`：ノーツごとに鳴らす楽器を選びます
- 録音の曲を作曲プログラムで作るとき：`info` に `tempo`、`stops`、`t0`、`bars`（小節ごとの和音）、`ghosts`（譜面にない旋律の音）、`voiceOf(note)`（ノーツごとの楽器）を書くと、`songs/dump-chart.js` が作曲プログラム用に書き出します。
  - `start` / `stop`：鳴らし続ける環境音
- 演出 `scene(kit, field)`：`back`（水面の下）、`surface`（水面の上）、`front`（いちばん手前）、`post`（描き終えた画面への加工）、`ring`（波紋の描き方）、`hit`（叩いたとき）、`reset`、`layout` を返します。
  - `field.rings` に、その瞬間の波紋の位置と大きさが入っています（波紋に反応する演出用）。
  - `field.flash()` で画面を光らせ、`field.shake()` で揺らせます。
