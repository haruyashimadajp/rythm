# MINAMO（水面のリズム）

雫が落ちて広がる波紋が、水面に浮かぶノーツに**届いた瞬間**に叩く音楽ゲームです。
`index.html` ひとつで動きます。ブラウザで開けば遊べます。

このブランチ（`minamo`）は、Rhythm Lab の「広がる円（MINAMO）」形式だけに絞ったゲームです。
ほかの形式の試作は元のブランチに残っています。

## 遊び方

- **パソコン**：マウスでノーツに合わせ、`Z` / `X` かクリックで叩きます。
- **スマホ**：ノーツを直接タップします。
- **ノーツの種類**
  - タップ：波紋が届いた瞬間に叩きます。
  - 長押し：波紋と一緒に外へ動く光を、押したまま追いかけます。
  - 回る長押し：渦を巻くように回りながら外へ動く光を追いかけます。
  - 水切り：跳ねてくる石が着水する点を叩きます。

自己ベストは端末に保存されます。

## 曲

1. **SHIZUKU 雫**（Lo-fi Hip Hop、BPM 84、レベル2）
   雨の夜の水たまりです。水面一面に雨の輪が広がり、街灯が水に映って揺れます。
2. **KOI 鯉**（Disco House、BPM 124、レベル4）
   陽の差す池です。鯉が泳ぎ、蓮の花がキックに合わせて弾みます。光の網が水底に揺れます。
3. **KOORI 氷**（Waltz 3/4、BPM 168、レベル5）
   凍った湖の夜です。波紋が六角形に広がり、叩くと氷にひびが走ります。雪が降り、オーロラがかかります。
4. **TOUROU 灯籠**（Matsuri Rock、BPM 150、レベル6）
   夏祭りの夜の川です。灯籠が流れ、サビでは花火が上がります。太鼓、鉦、三味線、篠笛、ギターが鳴ります。
5. **UZU 渦**（Drum & Bass、BPM 174、レベル8）
   嵐の渦潮です。渦が回り、ドロップでは雷が落ちて画面が揺れます。

音はすべて Web Audio でその場で合成しています。

## ファイル構成とビルド

`index.html` は `src/` の部品をつなげて作っています。編集するのは `src/` のほうで、編集後に `./build.sh` を実行すると `index.html` が作り直されます。

- `src/00-engine.html`：画面、判定、入力、音の土台、メインループ
- `src/10-field.js`：全曲共通の水面（譜面の書き方、波紋とノーツの描画、エフェクト）
- `src/20-shizuku.js` 〜 `src/60-uzu.js`：1曲ずつ
- `src/99-boot.html`：起動処理

## 曲の追加のしかた

`src/` に `70-xxx.js` のようなファイルを作り、`rippleSong({...})` を1つ書きます。番号順に曲選択に並びます。

- 曲の情報：`id`、`title`、`jp`、`genre`、`level`、`lede`、`theme`（パネルの色）、`hues`（波紋の4色）
- テンポと構成：`bpm`、`beatsPerBar`（3なら3拍子）、`bars`、`sections`、`chords`
- 波紋：`speed`（1拍で広がる距離）、`ring: { sides: 6 }` で多角形の波紋になります。
- 譜面 `chart({ drop, skip, B })`
  - `drop(B(小節, 拍), [x, y], 色, 'パターン', { a, turn, speed, spin })`
    雫を落とします。パターンは8分音符ごとに書き、`o` はタップ、`H` は長押し、`S` は回る長押し、`-` は長押しの続き、`.` は休みです。
  - `skip(B(小節, 拍), [x0, y0], [x1, y1], 色, 'パターン')`
    石が `[x0, y0]` から `[x1, y1]` へ跳ねていきます。`o` の位置で着水します。
  - 水面の座標は、横が約 ±0.74、縦が約 ±0.42 です。
  - 遠すぎて間に合わない並びや、重なる位置にあるノーツは、読み込み時にコンソールへ警告が出ます。
- 音 `song`
  - `lead`：ノーツの音色
  - `arrange(add, bar, b0, ch, name)`：伴奏
  - `instruments`：その曲だけの楽器
  - `extra(add)`：小節によらないフレーズ
  - `start` / `stop`：鳴らし続ける環境音
- 演出 `scene(kit, field)`：`back`（水面の下）、`surface`（水面の上）、`front`（いちばん手前）、`hit`（叩いたとき）、`reset`、`layout` を返します。
  - `field.flash()` で画面を光らせ、`field.shake()` で揺らせます。
