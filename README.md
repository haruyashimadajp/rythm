# rythm

次世代の音ゲーの「ノーツの取り方」を試すためのプロトタイプ置き場です。
どのプロトタイプも HTML ファイル 1 枚で動き、ビルドは不要です。

## プロトタイプ

### 編み込みレーン（Kumihimo Lanes）

`prototypes/braided-lanes/index.html` をブラウザで開くと遊べます。

- 4 本のレーンが組紐のように交差し、入れ替わり、ねじれます。
- キーは画面上の位置ではなく、レーンの色につながっています（D＝紅、F＝山吹、J＝浅葱、K＝藤）。
- 譜面は固定です。BPM 128、44 小節、約 1 分 25 秒。
- 曲は Web Audio API でリアルタイムに合成しているので、音源ファイルはありません。
- タイトル画面で、ハイスピード・判定オフセット・オートプレイを設定できます。
- スマホでは判定ラインの受け皿をタップして遊べます。

譜面（`BARS`）と編み込みの動き（`BRAIDS`）は、ファイル内のデータを書き換えるだけで調整できます。

### 変形する多角形（Kiriko Gate）

`prototypes/polygon-gate/index.html` をブラウザで開くと遊べます。

- 画面中央の多角形の辺が、それぞれ 1 本のレーンです。ノーツは外側から辺に向かって迫ってきます。
- 多角形は回り続け、曲の展開に合わせて 三角 → 四角 → 五角 → 六角 と形が変わります。辺は伸びて生まれ、縮んで消えます。
- 6 本の辺にはそれぞれ固定のキーと色があります（S D F J K L）。形によって使うキーが変わります。
- ノーツは「着弾するときの形」の辺として飛んでくるので、形が変わる前から次の形が見えます。
- スマホでは、中心から見て辺がある方向をタップします。
- BPM 140、44 小節、約 1 分 15 秒。曲は Web Audio API で合成しています。

譜面（`BARS`）、形の変化（`MORPHS`）、追加の回転（`TURNS`）はファイル内のデータです。

### 四辺反射（Kagami Walls）

`prototypes/four-walls/index.html` をブラウザで開くと遊べます。

- 箱の四方の壁がすべて判定ラインです。光の玉が決まった軌道で跳ね回り、壁に当たる瞬間にその壁のキーを押します。
- キーは ↑ ← ↓ → または W A S D（どちらも同じ働き）。両手で使い分けて同時押しもできます。
- 玉の色は「次に当たる壁」の色です。当たる地点には縮んでいく半円の目印が出て、その次の跳ね返り先も薄く表示されます。
- 長押しノーツでは、玉が壁に沿って滑ります。
- スマホでは、箱の対角線で分けた 4 つの領域のうち、壁の側をタップします。
- BPM 124、44 小節、約 1 分 25 秒。曲は Web Audio API で合成しています。

譜面は `TRACKS` に玉ごとの軌道として書いてあります（8 分音符単位、U R D L ＝ 当たる壁、小文字＋`-` ＝ 壁を滑る長押し）。

### 踊るレセプター（Hotaru Dance）

`prototypes/dancing-receptors/index.html` をブラウザで開くと遊べます。

- 受け皿（4 匹の蛍）そのものが、曲に合わせて画面中を踊ります。
- ノーツは光の筋として曲線を描き、蛍を追いかけて飛んできます。蛍に届いた瞬間に、その蛍の色のキーを押します（D＝若葉、F＝山吹、J＝空、K＝撫子）。
- 蛍のまわりに縮んでいく輪が出るので、届くタイミングを読めます。長押しノーツは長い光のリボンになります。
- 踊りはセクションごとに変わります（横一列 → 波 → ひし形の回転 → 8 の字 → 2 組のペア回転）。キックに合わせて小さく跳ねます。
- スマホでは蛍そのものをタップします。縦長の画面では踊りが 90° 回転して画面に収まります。
- BPM 132、44 小節、約 1 分 20 秒。曲は Web Audio API で合成しています。

踊りの形は `DANCES`、切り替えのタイミングは `DANCE_TL`、譜面は `BARS` です。

### 広がる円（Minamo Rings）

`prototypes/sonar-rings/index.html` をブラウザで開くと遊べます。

- 水面に雫が落ちると波紋が広がります。ノーツは水面に浮かんで待っていて、波紋が届いた瞬間にそのノーツを狙って叩きます。
- 「縮む円」の逆で、円は広がり、ノーツは動きません。いくつもの場所から同時に波紋が広がります。
- ノーツと波紋は色で対応していて、ノーツから雫の落ちた点へ細い点線が伸びます。ノーツは波紋が近づくにつれて中心から満ちていきます。
- パソコンはマウスで照準を合わせて Z / X かクリック、スマホはノーツを直接タップします（これまでの 4 つと違い、位置を狙う入力です）。
- 長押しノーツは、波紋と一緒に外へ動く光を、押したまま追いかけます。
- 縦長の画面では、水面全体が 90° 回転して収まります。
- BPM 120、44 小節、約 1 分 30 秒。曲は Web Audio API で合成しています。

譜面は `drop(拍, x, y, 色, パターン, 最初の角度, 角度の増分, 波紋の速さ)` の呼び出しで書いてあります。画面に収まらないノーツは自動で角度をずらします。

### 振り子判定線（Furiko Metronome）

`prototypes/pendulum/index.html` をブラウザで開くと遊べます。

- 判定線はメトロノームの振り子です。扇形に並んだ 4 本の帯（内側から D F J K）の上にノーツが置いてあり、振り子が通過した瞬間にその帯のキーを押します。
- 振り子は端でゆっくり、真ん中で速く動くので、同じ間隔のノーツでも、置かれる角度の間隔が変わります。
- 「今のひと振り」で当たるノーツははっきり、「次のひと振り」のノーツは輪郭だけで表示されます（振り子が同じ角度を何度も通るため）。
- 振り幅とひと振りの長さ（1・2・4 拍）が曲の展開で変わり、振り子のおもりの位置も実物のメトロノームと同じように動きます。Chorus II ではメトロノーム全体が左右に傾きます。
- 長押しノーツは帯に沿った扇形で、振り子がその上を掃いている間押し続けます。
- 振り子が端で折り返すたびに、木のクリック音が鳴ります。
- スマホでは、支点からの距離で帯を選んでタップします。縦長の画面ではメトロノームが横向きになります。
- BPM 126、44 小節、約 1 分 25 秒。曲は Web Audio API で合成しています。

振り方は `SWINGS`（小節, ひと振りの拍数, 振り幅）、譜面は `BARS` です。
