# MINAMO（水面のリズム）

雫が落ちて広がる波紋が、水面に浮かぶノーツに**届いた瞬間**に叩く音楽ゲームです。
`index.html` と、録音された曲の音源（`audio/`）で動きます。
録音の曲は音源を読み込むので、ファイルを直接開くのではなく、ウェブサーバー経由で開いてください（例：`python3 -m http.server` を実行して `http://localhost:8000/` を開く）。

このブランチ（`minamo`）は、Rhythm Lab の「広がる円（MINAMO）」形式だけに絞ったゲームです。
ほかの形式の試作は元のブランチに残っています。

## 遊び方

- **パソコン**：マウスでノーツに合わせ、`Z` / `X` かクリックで叩きます。
- **スマホ**：ノーツを直接タップします。
- **ノーツの種類**
  - タップ：波紋が届いた瞬間に叩きます。
  - 長押し：波紋と一緒に外へ動く光を、押したまま追いかけます。
  - 回る長押し：渦を巻くように回りながら外へ動く光を追いかけます。
  - 水切り：跳ねてくる石が着水する点を叩きます。
  - 交点：二つの波紋が交わる点です。`Z` と `X` を同時に（クリックとキーでも）、スマホは二本指で同時に叩きます。片方だけだと GOOD になります。
  - 連打：同じ点に波紋が続けて届きます。中の数字が残りの回数です。

判定に使う波紋（まだ叩くノーツが乗っている波紋）は太く明るく、残像や叩き終わった波紋、ソナーなどの飾りの波紋は薄く描いています。

自己ベストは端末に保存されます。

## 曲

1. **SHIZUKU 雫**（Lo-fi Hip Hop、BPM 84、レベル2）
   雨の夜の水たまりです。水面一面に雨の輪が広がり、街灯が水に映って揺れます。
   軒先の雫（同じ点の連打）、二つの雨粒の交点（同時押し）、窓を伝って流れる雫（中心が動く波紋）。
2. **KOI 鯉**（Disco House、BPM 124、レベル4）
   陽の差す池です。鯉が泳ぎ、蓮の花がキックに合わせて弾みます。光の網が水底に揺れます。
   波紋を連れて泳ぐ鯉（中心が動く波紋）、鯉の口パク（連打）、二匹の鯉の交点（同時押し）。
3. **KOORI 氷**（Waltz 3/4、BPM 168、レベル5）
   凍った湖の夜です。波紋が六角形に広がり、叩くと氷にひびが走ります。雪が降り、オーロラがかかります。
   波紋を連れて滑るスケーター、凍りついて止まる波紋（減速）、岸の向こうからの巨大な氷の波。
4. **TOUROU 灯籠**（Matsuri Rock、BPM 150、レベル6）
   夏祭りの夜の川です。灯籠が流れ、サビでは花火が上がります。太鼓、鉦、三味線、篠笛、ギターが鳴ります。
   太鼓の「ドコ」（連打）、波紋を乗せて流れる灯籠、開いてから止まる花火の波紋、二つの花火の交点（同時押し）。
5. **UZU 渦**（Drum & Bass、BPM 174、レベル8）
   嵐の渦潮です。渦が回り、ドロップでは雷が落ちて画面が揺れます。
   雷が落ちた所からの衝撃波、渦の目の周りを回る波紋、渦の目へ引き込まれて縮む波紋。

6. **PRISM 分光**（Melodic Trance、BPM 128、レベル7、録音）
   白い光が赤・緑・青の波紋に分かれて違う速さで広がり、色が交わる点で白い光になります（交点）。
   光源が縁を滑って糸の模様を描き、巨大な光の波が隅から押し寄せ、鏡の区間では波紋が左右に映ります。
7. **ABYSS 深淵**（Deep Sea Ambient、BPM 90、レベル7、録音）
   雫が沈みながら広がり、チョウチンアンコウの光から波紋が流れ、クラゲは広がっては縮む波紋で脈打ちます。
   暗い海ではソナーが届くまでノーツが見えず、反響が同じ点を連打させます。最後は深淵が波紋を引き込み、クジラの歌に乗って漂います。
8. **MALWARE 感染**（Glitch / Dubstep、BPM 150、レベル8、録音）
   四角いピクセルの波紋です。感染は叩いたノーツから次の波紋へ広がり、波紋は瞬間移動し、巻き戻り、
   テープが止まるとブルースクリーンへ落ち、フォーマットされて電源が切れます。

1〜5 の音は Web Audio でその場で合成しています。6〜8 は dodge-game のオリジナル曲の音源（`audio/`）を使い、
譜面はその曲の楽譜データ（作曲プログラムが書き出した拍のデータ）に合わせて作っています。

## ファイル構成とビルド

`index.html` は `src/` の部品をつなげて作っています。編集するのは `src/` のほうで、編集後に `./build.sh` を実行すると `index.html` が作り直されます。

- `src/00-engine.html`：画面、判定、入力、音の土台、メインループ
- `src/10-field.js`：全曲共通の水面（譜面の書き方、波紋とノーツの描画、エフェクト）
- `src/20-shizuku.js` 〜 `src/90-malware.js`：1曲ずつ
- `audio/`：録音の曲の音源
- `src/99-boot.html`：起動処理

## 曲の追加のしかた

`src/` に `70-xxx.js` のようなファイルを作り、`rippleSong({...})` を1つ書きます。番号順に曲選択に並びます。

- 曲の情報：`id`、`title`、`jp`、`genre`、`level`、`lede`、`theme`（パネルの色）、`hues`（波紋の4色）
- テンポと構成：`bpm`、`beatsPerBar`（3なら3拍子）、`bars`、`sections`、`chords`
- 波紋：`speed`（1拍で広がる距離）、`ring: { sides: 6 }` で多角形の波紋、`ring: { chroma: true }` で虹色のにじみが付きます。
- 録音の曲：`audioFile: { src: 'audio/xxx.mp3', t0: 0.5 }`（`t0` は音源の中で0拍目が来る秒数）、`pulse: kickPulse([キックの拍...])`
- 譜面 `chart({ drop, skip, B })`
  - `drop(B(小節, 拍), [x, y], 色, 'パターン', { a, turn, speed, spin })`
    雫を落とします。パターンは8分音符ごとに書き、`o` はタップ、`H` は長押し、`S` は回る長押し、`-` は長押しの続き、`.` は休みです。
  - `drop` の波紋の動き：`speed` を負にすると縮む波紋、`r0` で最初から大きい波紋（中心を画面外に置くと巨大な波紋）、
    `accel` で加速・減速、`path: [[拍, x, y], ...]` と `ease`（`'smooth'`／`'linear'`／`'step'`＝瞬間移動）で中心が動きます。
    `angs` で各ノーツの角度を直接決められ、`dark: true` でノーツが隠れます。
  - `skip(B(小節, 拍), [x0, y0], [x1, y1], 色, 'パターン')`
    石が `[x0, y0]` から `[x1, y1]` へ跳ねていきます。`o` の位置で着水します。
  - `wave(拍, [x, y], 色, { reveal: true })`：ノーツのない波紋。`reveal` で通り過ぎた暗いノーツを見せます（ソナー）。
  - `pulse(拍, [x, y], 色, { a, off, n, gap })`：同じ点に `n` 回届く波紋の列（連打）。
  - `cross(拍, 雫A, 雫B)`：二つの波紋がその拍に交わる点にノーツを置きます（交点、同時押し）。
  - `tip(雫, i)`：雫の i 番目のノーツの拍と位置。次の雫をそこから落とすときに使います。
  - 水面の座標は、横が約 ±0.74、縦が約 ±0.42 です。
  - 遠すぎて間に合わない並びや、重なる位置にあるノーツは、読み込み時にコンソールへ警告が出ます。
- 音 `song`
  - `lead`：ノーツの音色
  - `arrange(add, bar, b0, ch, name)`：伴奏
  - `instruments`：その曲だけの楽器
  - `extra(add)`：小節によらないフレーズ
  - `start` / `stop`：鳴らし続ける環境音
- 演出 `scene(kit, field)`：`back`（水面の下）、`surface`（水面の上）、`front`（いちばん手前）、`post`（描き終えた画面への加工）、`ring`（波紋の描き方）、`hit`（叩いたとき）、`reset`、`layout` を返します。
  - `field.rings` に、その瞬間の波紋の位置と大きさが入っています（波紋に反応する演出用）。
  - `field.flash()` で画面を光らせ、`field.shake()` で揺らせます。
