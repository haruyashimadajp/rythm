水面の輪 ・ 広がる円のプロトタイプ

水面に雫が落ちると波紋が広がります。ノーツは水面に浮かんで待っていて、波紋が届いた瞬間に、そのノーツを狙って叩きます。同じ色の波紋が、そのノーツの合図です。

  • パソコンマウスでノーツに照準を合わせ、Z X かクリックで叩く
  • スマホノーツを直接タップ
  • 長押し波紋と一緒に外へ動く光を、押したまま追いかける
1.0 ノーツが浮かび上がる早さ（波紋の速さは曲で決まっています）
0 ms 音が遅れて聞こえるときは ＋ 側へ
Space で開始 ・ プレイ中は Esc で中断

BPM 120 ・ 44小節 ・ 約1分30秒 ・ 曲はブラウザ内でリアルタイム合成
